Learn how to control the turtle robot and understand the basics of programming movement.

🐢 What is a Turtle Robot? Concept

A turtle robot is a simple programmable robot that moves around and draws lines. You give it instructions like "move forward 100 steps" or "turn right 90 degrees" and it traces a path. This is how kids first learned to code in the 1960s with a language called Logo!

📐 How Squares Work Example

A square has 4 equal sides and 4 right-angle corners. To draw one, repeat 4 times: move forward, then turn right 90°. The total turning is 4 × 90° = 360° — a full circle!

💡 Try the Square button in Quick Draw to see this in action, then use Undo to go back step by step.

⭕ How Circles Work Example

A circle is drawn by taking 36 tiny steps, each with a 10° turn. 36 × 10° = 360° — another full rotation, but with short steps so it looks round.

🌀 How Spirals Work Example

A spiral increases the step size each iteration. Move forward a little, turn, then move forward a little more next time. The growing steps push the path outward.

🎨 Pen Controls

Toggle the pen up/down to draw dotted paths or lift the turtle to move without drawing. Change pen color and size to create colorful artwork. Try drawing a shape, changing the color, then drawing another on top!
