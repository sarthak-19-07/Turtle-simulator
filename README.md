# Turtle-simulator

# Overview
This project is a beginner-friendly introduction to robotics using ROS2 and TurtleSim. It demonstrates basic robot movement, path planning, and Python programming concepts through a virtual turtle robot.
# Features
- ROS2 TurtleSim simulation
- Draw geometric shapes using Python
- Generate spiral movement patterns
- Keyboard-controlled turtle robot
- Visual journey map using Matplotlib
- Beginner's guide: "What I Learned About Robots in 4 Weeks"
# Learning Outcomes
- Understanding ROS2 basics
- Publishing and subscribing to topics
- Robot movement control
- Coordinate tracking and visualization
- Basic robotics programming concepts
# Project Goal
To provide a simple and interactive platform for learning robotics concepts without requiring physical hardware.
